# UI/Product Review — SEZ.26

Use this skill for substantial UI/UX work.

## Goal

Evaluate and improve the agent workflow using modern customer-service-inbox principles inspired by Help Scout, without copying Help Scout's visual identity or changing SEZ.26 business rules.

## Review sequence

1. Inspect the existing screen and surrounding components before editing.
2. Identify friction in navigation, hierarchy, density, affordances, loading, empty/error states, keyboard flow, and responsive behavior.
3. Prefer coherent product-level changes over isolated cosmetic tweaks.
4. Preserve existing data contracts and business semantics.
5. Keep actions discoverable and reduce unnecessary navigation.
6. Use status/category/channel colors only when they communicate meaning.
7. Avoid adding dependencies unless clearly justified.

## Validation

After implementation, verify the affected flow at desktop size and, when practical, a narrower viewport. Check focus states, keyboard behavior, loading, empty, error, success, and destructive-action states.
