# SEZ.26 — Project State

## Product
Customer case management and tracking application for service agents.

## Architecture
React + TypeScript + Vite + Supabase; originally created with Google AI Studio (App).
Deployment flow: Google AI Studio → GitHub → Cloudflare Pages.

## Git reference
Repository: https://github.com/CLR26/sez.26.git
Production branch: main

## Product direction
Use Help Scout as a behavioral/interaction reference for a modern support inbox: work-oriented views, fast list-to-detail flow, clear status/ownership, quick actions, conversation-style journal, and easy next/previous navigation. Do not copy Help Scout's UI or business states.
